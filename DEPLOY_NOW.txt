# 🚀 배포 명령어 (하나씩 복사해서 터미널에 붙여넣기!)

## 1단계: 프로젝트 폴더로 이동
cd romantic-humanist-portfolio

## 2단계: Git 사용자 설정 (처음 한 번만)
git config --global user.name "낭만적 인본주의자"
git config --global user.email "skyat23@naver.com"

## 3단계: 변경사항 저장
git add .
git commit -m "모바일 최적화 완료 - 배포 준비"

## 4단계: GitHub 저장소 만들기
# 웹 브라우저에서 https://github.com/new 접속
# Repository name: romantic-humanist-portfolio
# Public 선택
# Create repository 클릭
# 생성된 URL 복사 (예: https://github.com/yourusername/romantic-humanist-portfolio.git)

## 5단계: GitHub에 업로드 (YOUR_GITHUB_URL을 실제 URL로 변경!)
# 예시: git remote add origin https://github.com/yourusername/romantic-humanist-portfolio.git
git remote add origin YOUR_GITHUB_URL
git branch -M main
git push -u origin main

## 6단계: Vercel 배포
# 1. https://vercel.com 접속
# 2. "Sign Up with GitHub" 클릭
# 3. "Add New..." → "Project"
# 4. romantic-humanist-portfolio 선택
# 5. "Deploy" 클릭!

## 완료! 🎉
# 1-2분 후 배포 완료
# URL: https://your-project.vercel.app
